{%- comment -%} Browser-tab title. `page.title` alone gave the 57 generated MSEQ pages titles like "Swing" and "Trigs": indistinguishable in a tab strip, a bookmark list or a search result, and with nothing to say they belong to MSEQ, to the documentation, or to this site. The suffix supplies that context, most-specific first, so a truncated tab still shows the page's own name. Pages whose own title already says MSEQ — the manual, the contents page — skip that segment rather than stutter it. The suffix is chosen here from the URL rather than set in each page's front matter, because the MSEQ pages are build output from the sequencer repo's scripts/build_site_docs.py and carry only layout, title and permalink. Editing them is not an option; they are overwritten on every publish. {%- endcomment -%} {%- capture page_title -%} {%- if page.url == '/' or page.title == nil or page.title == empty -%} {{ site.title }} {%- elsif page.title contains 'MSEQ' -%} {{ page.title }} · MDMA {%- elsif page.url contains '/documentation/MSEQ' -%} {{ page.title }} · MSEQ docs · MDMA {%- else -%} {{ page.title }} · MDMA {%- endif -%} {%- endcapture -%} {{ page_title | strip }} {%- seo title=false -%} {% if page.robots %} {% endif %} {%- comment -%} One stylesheet, because there is one theme. This used to branch on `site.style` to main-light.css and main-hacker.css, neither of which has ever existed: setting the option served a page with no styles at all. The remaining branch was no better — main.scss and main-dark.scss both `@import "dark"`, so every arm compiled to the same bytes. A light theme means adding _sass/_light.scss and honouring prefers-color-scheme here; until then a single link is the honest thing. {%- endcomment -%}
